# Performance Analysis

This directory contains the results and analysis of the empirical performance benchmarks.

## Files

- `algorithm_runs.csv`: Raw data from all benchmark runs, including algorithm name, input size, average time (nanoseconds), and average memory usage (kilobytes).
- `analysis.md`: A qualitative analysis of the results, comparing observed performance with theoretical Big-O complexity for selected algorithms.
- `plot_results.py`: A Python script to generate performance graphs from `algorithm_runs.csv`.
- `*.png`: Graph images generated by the plotting script.

## Generating Graphs

To regenerate the graphs, ensure you have Python 3, `pandas`, and `matplotlib` installed, then run the script from this directory:

```bash
pip install pandas matplotlib
python plot_results.py
```
